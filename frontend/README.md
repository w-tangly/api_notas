# Frontend - Bloco de Notas

Interface web moderna desenvolvida em HTML5, CSS3 e JavaScript Vanilla.

## Execução

1. Acesse a pasta do frontend:
   ```bash
   cd frontend
   ```

2. Inicie o servidor frontend:
   ```bash
   npm start
   ```
   *(ou `npm run dev` para recarregamento com `--watch`).*

3. Abra no navegador:
   **[http://localhost:5000](http://localhost:5000)**

> **Nota:** Certifique-se de que o backend esteja em execução na porta 3000 (`http://localhost:3000`) para que as notas possam ser listadas, criadas, editadas e excluídas.
